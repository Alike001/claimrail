# Presentation assets

These images document the locally verified interface. They are not substitutes for the required
public testnet claim and delivery evidence.

| File                    | Source                                                  | Safe use                                       |
| ----------------------- | ------------------------------------------------------- | ---------------------------------------------- |
| `landing-local.png`     | Local production build                                  | README, draft submission layout, demo planning |
| `developers-local.png`  | Local production build                                  | Developer-experience preview                   |
| `docs-local.png`        | Local production build                                  | Documentation preview                          |
| `positions-sample.png`  | Development fixture; page labels fixture/no live funds  | README and UI review only                      |
| `evidence-sample.png`   | Development fixture                                     | UI review only                                 |
| `receipt-sample.png`    | Captured protocol fixture; page says demonstration only | UI review only                                 |
| `alerts-local.png`      | Local unconnected state                                 | UI review only                                 |
| `deliveries-sample.png` | Verified UI fixture; page says no live delivery data    | UI review only                                 |

Before submission, add a separate set of live assets with names beginning `live-`:

- `live-positions.png`;
- `live-evidence.png`;
- `live-wallet-review.png`;
- `live-confirmed-receipt.png`;
- `live-delivery.png`.

Every live image must be captured from the deployed HTTPS site and must contain no secret, provider
credential, private account identifier, or wallet recovery material.
